# Blog Aggregator

This is a RSS Feed aggregator made from the [boot.dev](https://boot.dev) course.

install it using 

```
go install github.com/Uami-11/blog-aggregator@latest
```

## Commands you can use

`register` - lets you register a user
`login` - lets you log into an already registered user
`reset` - gets rid of all users and feeds from the database
`users` - shows you all the users in the aggregator
`agg` - aggregates all posts from feeds you follow
`addfeed` - lets you add a feed 
`feeds` - shows you all the feeds from the database
`follow` - lets you follow certain feeds
`following` - shows you all the feeds you follow
`unfollow` - lets you unfollow a feed you follow
`browse` - shows you posts from the feeds you follow
